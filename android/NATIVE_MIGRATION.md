# Native Android migration

Branch: `codex/native-android`. The new package is `com.aceinandroid.inkflow`; it installs alongside the Flutter application. The native build uses Kotlin and Compose with minSdk 24, compileSdk 36, and targetSdk 35.

## Native v0.2 migration (2026-11-26)

The current P0–P3 implementation and acceptance scope are recorded in
[NATIVE_MIGRATION_PLAN.md](NATIVE_MIGRATION_PLAN.md). Native AI follows the
[shared architecture contract](../docs/architecture/native-ai-contract.md).
CloudBase sync has been removed from the native migration scope. It is not a
native dependency, setting, or future acceptance requirement.

The Android build now has `standard` and `fullOcr` flavors. Use explicit variant
names, for example `:app:assembleStandardDebug` and `:app:assembleFullOcrDebug`;
historical unflavored commands below describe earlier acceptance runs.

## Implemented

- Standalone Android Gradle build with no Flutter plugin or runtime in its APK.
- The bookshelf displays bounded thumbnails from Flutter-restored `cover/` paths. Native EPUB imports extract OPF-declared EPUB 2/3 cover images into the shared cover directory; removing a book cleans up its cover alongside its imported file. Books without a usable cover retain a format label.
- System document import (including new intents delivered to an existing `singleTop` activity), single and multiple-file Android share intents, FB2 and Markdown VIEW MIME types, duplicate detection, a searchable local bookshelf with confirmed book removal, and chapter/page position saved on the device. A bad file in a batch does not prevent the remaining imports, and the bookshelf refreshes after partial success.
- Bookshelf sorting supports title, author, last read, reading progress, and import time in either direction. EPUB, PDF, and text reading update the shared book progress and last-read timestamp; Flutter local timestamps and native UTC timestamps sort by instant. Sort preferences persist, round-trip in native settings version 4, and map from Flutter backups. Versions 1 and 2 remain readable.
- The bookshelf reads Flutter v22 `tb_groups` and `tb_books.group_id`, shows all books, unfiled books, and named folders with nested paths, and can create child folders, rename, move, or delete folders, and move books between folders. Folder moves reject cycles and deleted destinations. Deleting a folder moves its books and child folders to its parent in one database transaction. Group IDs and parent relationships survive native ZIP and WebDAV database restores.
- EPUB text extraction; PDF page rendering through `PdfRenderer`. FB2 reads declared XML encodings and builds chapters and a nested directory from the primary body's sections without repeating nested text or indexing footnotes as chapters. Its common emphasis, strong, strike, poem, and subtitle markup flows through the native rich-text renderer; embedded bitmap resources load from FB2 binary elements. TXT detects UTF-8, BOM-marked UTF-16/UTF-32, common unmarked UTF-16, and GB18030, recognizes Chinese and English chapter headings, and splits long unheaded books near 20,000 characters at line breaks. TXT chapters share their text offsets with search, contents, narration, and local resume position. Markdown uses CommonMark parsing for heading-based chapters and a nested directory, plus basic inline styles, list markers, code, and table rows in the native reader. Unsupported embedded images remain visible as alt text.
- TXT chapter rules in Settings offer four built-in patterns and editable custom regular expressions with sample matching, case sensitivity, and multiline controls. A newly imported TXT book stores its selected rule as a per-book snapshot, so later rule edits or deletion do not shift its contents or saved chapter position. Native backups round-trip rules and snapshots in settings version 2; version 1 settings remain readable, and Flutter chapter-rule preferences map into native settings on restore.
- PDF pages can switch between their original rendered image and selectable text; search results open the matching page in text mode. Pages with no extractable PDF text use bundled on-device Chinese/Latin OCR for text mode, search, selection, and narration. Rendered pages are bounded to four million pixels; OCR text for up to 256 pages is cached in memory per file version.
- DRM-free MOBI and AZW3/KF8 chapter extraction through bundled LGPL-3.0 `libmobi`. Extracted HTML, NCX, and bitmap resources are cached next to each private book file and removed with the book. Chapter search, NCX directory navigation (including nested entries and anchors), and narration use the existing text reader. The Compose reader renders common inline styles and embedded bitmap images in measured content blocks.
- EPUB spine and XHTML text positions use native CFI generation/resolution. EPUB reading progress is stored in the v22 `last_read_position` field and can reopen an existing foliate-js position. The Compose renderer preserves common inline text styles and decodes embedded bitmap images in measured content blocks.
- Referenced SVG image resources render through the same bounded image decoder as bitmap resources in EPUB, FB2, and MOBI/AZW3. EPUB inline SVG markup and base64 image data URIs also render as measured image blocks while preserving the CFI position of following text. SVG output is capped at 2048 pixels per side and four million pixels total.
- EPUB bookmarks can be added, listed, revisited, and deleted. They use the Flutter client's `tb_notes` rows with `type = 'bookmark'`, CFI, chapter, and percentage fields.
- EPUB text can be searched across chapters. Results include a chapter and excerpt, navigate to the matching text, and save a compatible CFI. TXT, Markdown, and FB2 results navigate to their text offset; PDFBox extracts searchable PDF text one page at a time, and results jump to the matching page.
- EPUB text selection can save highlights, underlines, and reader notes in the shared `tb_notes` schema. Range CFIs match foliate-js for text nodes; saved marks render in the native reader and can be revisited, edited, or deleted. Paragraph-sized selection controls keep a long-press near its visible position.
- A library-wide reading-notes view searches and filters EPUB highlights, underlines, and bookmarks from active books. Selecting an entry reopens the book at its CFI; returning from the reader reloads the list.
- The native reading-notes view also loads Flutter v22 workspace documents from `tb_reading_notes` with their text/quote blocks, annotation sources, tags, status, and favorite flag. Mapped legacy annotations appear once. Recent, inbox, questions, archived, favorites, and trash collections have counts; book, tag, legacy type, capture-kind, and source-type filters are available. Editing, manual note creation from an active book, revision history with preview and restore, batch status actions, and permanent deletion are available. Restoring a revision records a new version and preserves the current favorite flag. Editing a legacy annotation creates a compatible workspace document and keeps its `tb_notes.reader_note` in sync; deleting a linked document permanently also removes its annotation so it does not reappear as an unmapped legacy note.
- Workspace documents display preserved AI blocks with provider/model provenance and can copy their text into the editable note body. User-owned checklist blocks can be added, checked, edited, and deleted; block metadata is retained on updates, and AI-owned blocks are protected from checklist mutations.
- The reading-notes view exports its current search and type-filtered results as Markdown through Android's document picker, including book, chapter, note text, and CFI location.
- The native vocabulary view reads Flutter v22 `tb_vocabulary` rows, shows all and due words with totals and search, and applies Flutter-compatible hard, familiar, and mastered review intervals. EPUB, TXT, Markdown, FB2, MOBI/AZW3, and extracted PDF text selection can save a word with editable definition, source sentence, book, chapter or page, and a CFI or native chapter/page offset. Saved source locations reopen their book in the native reader. New English words are saved immediately, then a network-constrained WorkManager task fills missing v22 phonetic, audio URL, part of speech, English definition, and example fields from the same public dictionary used by Flutter; manual definitions are preserved. Word details play a validated HTTPS pronunciation URL when available and fall back to system TTS on error or after 15 seconds of preparation, with stop control and audio focus. Duplicate normalized words are not inserted; vocabulary rows round-trip through native ZIP backups. English and Chinese strings cover the current native screens.
- Foreground reading sessions accumulate seconds by book and local date in the compatible `tb_reading_time` table, including sessions that cross midnight. The native statistics view shows overall totals and navigable week, month, year, and all-time history; chart buckets filter the per-book totals, and the month view uses a compact date grid.
- Reader appearance controls adjust font size, line spacing, system or imported TTF/OTF/TTC font family, and light/warm/dark or custom foreground/background colors for EPUB and plain-text formats. Imported fonts are validated and copied into app-private storage, can be selected or removed from the shared appearance dialog, and persist across app restarts. EPUB keeps its current text position when typography changes.
- EPUB text blocks honor XHTML `align` and `text-align` from inline styles, embedded `<style>`, and relative linked CSS (start, end, left, right, center, justify). The same CSS sources support `font-weight`, `font-style`, `text-decoration`, `text-decoration-line`, common text colors, and relative or absolute `font-size` values. CSS font sizes follow parent and root values within a bounded range; publisher colors with low theme contrast fall back to the reader foreground. Simple tag, class, ID, descendant, and child selectors use cascade priority; conditional rules are skipped. These styles do not change CFI text offsets.
- Text readers can display three paired built-in day/night background images or imported JPEG, PNG, and WebP files. The appearance dialog selects day or night, automatic theme matching, cover or stretch fit, opacity and blur, and can remove an imported image. Imported images are confined to `bgimg/`, limited to 20 MB and 12,000 pixels per side, and decoded down to at most 2048 pixels per side and four million pixels. Flutter `bgimg`, `bgimgFit`, and `autoAdjustReadingTheme` preferences map into native settings on restore; native ZIPs round-trip selected images and their files.
- A native settings screen exposes persistent default reading appearance, narration speed/pitch, voice, and continuous chapter playback before opening a book.
- Volume-key page turning defaults on, can be disabled in Settings, and moves by roughly one viewport within a text chapter before changing chapters or PDF pages. Direction keys, Page Up/Down, and Space use the same reader navigation without relying on the volume-key setting. Returning to a previous text chapter opens near its end. Native ZIP backups round-trip the volume setting, and Flutter's `volumeKeyTurnPage` preference maps into native settings on restore.
- System text-to-speech reads EPUB from the current text offset, plain-text chapters from the visible line, and PDF text from the current page. It supports play, pause, resume, stop, speed, pitch, voice selection, and audio focus. An Android foreground media service keeps narration active in the background and exposes play/pause and stop in a media notification and media session. With continuous playback enabled, a naturally finished text chapter loads and reads the next chapter; manual chapter changes, stopping, and leaving the reader stop speech. Narration options persist across reader sessions and can also be changed in Settings.
- SQLite v22 creation from the existing Dart schema. The database is named `app_database.db`, books use relative `file/` paths, and MD5 is stored in `file_md5`.
- Native recovery of Flutter ZIP backups from Settings. The importer stages files in private storage, checks ZIP paths and size, validates the v22 database and referenced books, checkpoints a bundled WAL, and rolls back interrupted replacements on the next launch. It accepts duplicate database entries emitted by the Flutter encoder and ignores unrelated files in the backup's `databases/` directory. It preserves `anx_shared_prefs.json` and maps compatible line spacing, reading theme colors, system TTS rate, and pitch into native settings. The Flutter Android TTS rate is doubled by its plugin; native settings from `native/settings.json` take precedence.
- Native ZIP export through Android's document picker writes the v22 database, book files, covers, Flutter font/background directories, and any preserved Flutter preferences. A versioned `native/settings.json` and `native/fonts/` extension round-trips native reader appearance, narration, chapter offsets, and imported fonts. Flutter's ZIP importer can still read the shared library paths and ignores the native extension.
- Self-hosted EPUB progress sync uses the existing v1 HTTPS service protocol. Native page positions are saved per installation in `tb_book_device_positions`; login, logout, manual sync, and opt-in automatic sync are in Settings. Automatic sync runs on foreground resume or after leaving the reader, with a five-minute attempt cooldown. Remote progress is merged by timestamp and offered as an explicit jump when another device is more than 1% ahead; dismissing the offer preserves the current position. The download cursor advances only after local merge and uploads finish. Endpoint, token, cursor, and device identity stay in local preferences and are excluded from ZIP backups.
- When an EPUB reader goes to the background, its visible position is saved and a network-constrained WorkManager job uploads pending progress even if the app process exits. New local positions bypass the five-minute idle-sync cooldown; failed uploads remain pending and retry with backoff. The worker checks for a position saved during its own upload before finishing. Restoring a library resets the local upload marker so restored positions can sync.
- Manual WebDAV whole-library upload and download use the Flutter paths `anx/database22.db`, `anx/data/file/`, and `anx/data/cover/`. HTTPS account credentials are kept in Android Keystore-backed local preferences and excluded from ZIP backups. Upload publishes referenced files before the database and checks the remote database metadata again before publishing. Database creation uses `If-None-Match: *`, while replacement uses `If-Match` when the server supplies a strong ETag; HTTP 412 is reported as a remote-change conflict. Download stages the v22 database and every referenced book/cover, then uses native backup validation and rollback to replace the library. Both directions require an explicit confirmation; a newer remote database version is rejected. Download retains device appearance, narration, and custom TXT rules, but clears book-specific TXT rule snapshots and local non-EPUB chapter positions.

## Remaining before full Flutter parity

The new migration status document is authoritative for P0–P3. Features below
remain separate from completed native entry points and local contract checks:

- Complete publisher CSS/layout, fixed layout interoperability, inline image flow,
  full vector/multimedia support and comprehensive CFI edge cases; direct text
  selection over the PDF raster and OCR of image regions on mixed text/image pages.
- Full support for every MDX encoding/compression/encryption variant. Provider
  interoperability and voice availability require configured credentials; Edge's
  unofficial speech protocol is not part of the official REST integrations.
- Whole-library automatic two-way database merge and remote orphan cleanup.
  Manual whole-library WebDAV remains conditional and non-atomic across multiple
  files. Live WebDAV/server interoperability is a separate acceptance check.
- Full Android feature parity on iOS/iPadOS, additional languages beyond the
  native shell, Play Billing, folder drag-and-drop and cross-client Flutter import
  of edited native workspace documents. Legacy Flutter sources remain references.
- Other preserved Flutter preferences may not map to native controls. Relative
  `em` fonts cannot reliably map to `sp`; restored Flutter ZIPs do not supply
  native chapter offsets. Background blur and tablet/E-INK interaction still need
  broader device checks. Portable ZIPs exclude provider/TTS/sync credentials.

Non-EPUB chapter/page positions stay in local preferences; TXT, FB2, MOBI/AZW3, and Markdown also save a chapter-relative text offset. EPUB positions use the compatible v22 CFI field. The current renderer supports only a small XHTML style subset; images occupy their own blocks, and bitmap images use placeholder dimensions when XHTML omits width and height. `test/dao/export_native_schema_test.dart` checks the asset against the Flutter schema; regenerate it with `EXPORT_NATIVE_SCHEMA=1 flutter test test/dao/export_native_schema_test.dart` when that schema changes.

## Android language selection (2026-11-26)

The Android app now defaults to a device-local Automatic mode, resolving region,
explicit IANA time zone, ordered raw system languages, then English. Settings has
an immediate manual picker for Simplified Chinese, English, Japanese and Korean.
Android 13+ application-language settings reconcile bidirectionally; Android
12 and earlier retain ComponentActivity with configured resources. The locale
preference is excluded from portable ZIP/WebDAV settings, with no schema change.

Activity resources, Compose resources, existing dialogs, background media
notifications and date/number presentation use the effective UI language. Stable
contexts retain navigation and the current reader; existing reader save paths
remain responsible for progress. Built-in Skills and statuses are localized by
stable ID without translating stored content or triggering a model. Short-screen
AI panels reserve room for translated controls and the composer. Both APK variants
carry all four languages; AAB language splitting is disabled for offline selection.

results are recorded in [LOCALIZATION.md](LOCALIZATION.md). Earlier language
smoke results above covered resource availability rather than this new controller.
