## 实现边界与参考

Android Compose、KMP 核心、未来 SwiftUI；不用 React Native。复用现有书库、统计、词汇、笔记、设置、任务与播放器服务，不因路由换代创建新存储或 Provider。

参考是外部批准计划对两段录屏的拆解：基础阅读/书架/听书 `1838502f…mp4`（03:01）及 AI 问书 `43371dd0…mp4`（01:19）。下列尺寸/时序是批准的规格目标；视觉验收须用可用的原始参考和真实构建校对，保持原生可访问性，不复制品牌资源。

## 一级导航与返回

| 一级入口 | 内容与次级去向 | 状态保持 |
| --- | --- | --- |
| 首页 | 可定制阅读桌面、继续阅读、最近阅读、阅读历程、座右铭、桌面设置 | 四风格/布局/背景/最近书本地恢复 |
| 书架 | 本地书网格、搜索、导入、分组、批量管理、书籍详情 | 搜索、排序、文件夹、滚动和选择态保持 |
| 我的 | 知识（笔记/词汇/卡片/成果）、洞察（统计/本地成本）、设置 | 子页逐层返回；不增加一级 Tab |

手机底部仅三项；宽屏用同样三项的 NavigationRail。阅读器进入全屏，返回恢复来源 Tab 与滚动位置；外部导入、通知、深链仍能进入原业务页。选中重复 Tab 不重新导入或请求 AI。首次无历史默认首页；有明确“恢复阅读”设置按其恢复，不强制开书。

全局听书迷你条浮于导航上方，展示书名、播放/暂停、展开与关闭；不遮内容/键盘/系统手势。全屏播放器返回保留音频与位置；停止/关闭遵循明确动作。

历史验收基线为五项导航；当前 [MainActivity.kt](../../android/app/src/main/kotlin/com/aceinandroid/inkflow/MainActivity.kt) 已有 HOME/LIBRARY/ME 三项一级路由，[HomeScreen.kt](../../android/app/src/main/kotlin/com/aceinandroid/inkflow/ui/home/HomeScreen.kt) 已有四首页与设置实现，均待当前构建的新验收。迁移只调整路由归属，不删除原能力；代码存在不等于整阶段交付。

## 首页：四种风格一次交付

四种风格共享本地 `Home` 数据投影与桌面设置，不能各自扫描正文或创建 AI 管线。桌面可显示时间、日期、座右铭、最近阅读、进度/时长历程；书籍金句只有用户点击“设为座右铭”才入设置，可编辑、恢复默认。未打开/未读书显示本地空态和导入入口；不编造阅读数据。

| 风格 | 构成与视觉 | 操作与降级 |
| --- | --- | --- |
| 经典 | 清楚的时间/座右铭、最近阅读主卡、历程与快捷入口 | 稳定卡片分组，适合默认日常使用 |
| 壁纸沉浸 | 用户选本地壁纸、时间、低密度文字与主书封；遮罩保证可读 | 支持裁切/替换/移除；缺文件回退纯色，不联网下载 |
| 极简 | 大量留白、单本继续阅读、时间/一句座右铭；其他入口收起 | 完整操作仍在三 Tab 和桌面设置可达，不靠隐形手势 |
| E-INK | 纯色、高对比、线框封面/卡片、静态历程、大点击目标 | 3D/阴影动画/渐变/壁纸过渡关闭；刷新事件合并 |

最近阅读主卡在普通屏可用 3D 书封翻开展开；E-INK 与系统减少动画为 0ms 直切。书不存在时移除失效引用并提供书架入口，不显示不可点击封面。时间按分钟更新且在不可见时停止；E-INK 避免秒级刷新。历程仅读本地统计，无远端遥测。

桌面设置提供风格四选一、显示组件、壁纸、座右铭、最近阅读展示与恢复默认。四风格必须全部有空态、真实书库态、旋转/进程恢复与四语言布局证据，才可放行 v0.3。设备 E-INK 能力优先于用户风格：即使选经典，也保持静态安全渲染。

## 书架、导入与详情

- 搜索条目标高 40dp、全圆角；可触达区域至少 48dp。旁边 `⊕ 导入` 和 `✓ 选择` 入口常见可达；搜索仅本地书库。
- 手机默认三列，书封宽高比 **1:1.44**，网格尾部浅灰 `+` 卡。宽屏保持封面比例、按可用宽度扩列或限内容宽；大字号/窄屏可降列保证标题不互相覆盖。
- 长按封面进入多选，顶栏显示数量、全选、移动分组、删除/取消；删除书籍单独确认，批次失败逐项展示，成功项保留。
- 导入弹层聚合本地文件/系统分享/无线传书；多文件选择、重复检测、部分成功复用既有实现。Skill 导入从 AI 方法管理进入，传书页面明确区分书籍与 Skill，不凭 `.md` 扩展名误认所有 Markdown 为 Skill。
- 分组、排序和搜索保持现有 v22 规则；移动不成环、删除文件夹时迁移书籍/子目录的现有事务不变。
- 书籍详情为全屏原生页，含封面、书名/作者/格式、本地文件与阅读信息、继续阅读、只读已有成果入口、编辑与管理。生成入口需有有效本书上下文和范围确认，不能在详情页偷偷发送。

## 我的与设置

“我的”以浅灰页面底（浅色参考 `#F5F6F8`）、白色 14–16dp 圆角卡构成；知识与洞察入口成双列卡，小屏或大字号降为单列。书籍笔记、全局词汇、知识卡及阅读统计仍复用现有数据来源。计数没有数据时显示 0/空态，不用演示成绩。

设置为分组卡，行内图标、主文、副文、箭头或胶囊 Switch；进入使用原生推入/返回，E-INK 直接切换。分组含外观与桌面、阅读与听书、AI/阅读方法、词典、导入/备份/同步、语言与可访问性、关于。状态改变应即时反馈；凭据保存/验证复用既有安全存储。

## Design Tokens 与双层皮肤

目标 tokens 可按真实设备校准，但调整必须保持全页一致并记录偏差。

| 语义 | 规格目标 |
| --- | --- |
| 品牌强调 | 钴蓝参考 `#2F65D9`；深色/E-INK 用符合对比度的变体，不把语义只编码为颜色 |
| 页面/卡片 | 浅色页面 `#F5F6F8`、卡片白；深色使用独立 surface/onSurface 配对 |
| 圆角 | 功能卡 14–16dp；搜索/输入/选区主栏胶囊；禁止所有组件混用随机圆角 |
| 间距 | 4/8/12/16/24/32dp 网格；页面边距通常 16dp，宽屏适当增加 |
| 操作目标 | 至少 48dp；E-INK 大目标配置增大；图标含四语语义标签 |
| 字体 | 系统可访问字号；标题/正文/副文分级，允许日/韩文换行；正文排版独立 |
| 运动 | 普通屏短暂非循环过渡；E-INK/减少动画无依赖动画的信息表达 |

**App 皮肤**为跟随系统/浅色/深色，影响导航、卡片、面板和设置；**阅读皮肤**仅影响正文与相关排版资源，提供五种目标色板：纸白、暖纸、护眼绿、灰底、夜读。阅读器内切色不改变 App 外观，App 模式切换不重置正文色板/字体/位置；自定义颜色、纸纹和背景图保持现有导入能力。弹层采用可读的 surface 组合，避免暗正文上出现低对比卡片。

E-INK 是设备显示策略而非第六种阅读皮肤，也不等同于首页 E-INK 风格；关闭动态刷新、保留线框/静态高亮、禁用圆形放大镜与拖边扩选。阅读皮肤保存与首页风格保存为独立偏好。

## 阅读器 Chrome 与五图标底栏

正文中央明确点击切换 Chrome，右下浮现 **AI｜听** 两个圆钮；按钮有文字/语义，不能只靠陌生图标。顶部含返回、书名/章节和更多。五图标从左到右如下，顺序稳定：

| 图标入口 | 面板内容 |
| --- | --- |
| 搜索/目录 | 搜本书、目录、AI 大纲分区；大纲是已有 Wiki 的安全投影，未建立时显式生成 |
| 笔记/资料 | 我的笔记、AI 资料与本书成果；默认已读可见，查看全部需独立授权 |
| 进度/明细 | 章节/页码/全书进度、跳转、本书阅读明细柱状图；估算页码明确标注 |
| 亮度/外观 | 一体粗胶囊亮度，五皮肤、纸纹/背景；退出阅读恢复系统亮度 |
| 排版/翻页 | 对称双胶囊边距/行距，字号、段距/字体、翻页模式与宽屏双页开关 |

书签在顶部可直接添加/移除；下拉快捷是附加路径，不能与选区冲突。五面板单次只开一处，返回先关键盘/子页/当前面板。Chrome/面板切换不销毁正文，不触发模型。

## 手机单页、平板对开与 AI 协作

| 有效可用宽度/状态 | 正文 | AI/其他面板 |
| --- | --- | --- |
| <840dp 手机、折叠或窄分屏 | 单页 | AI 默认约 90% 高的单页 Sheet，可收起/展开；IME 弹出输入仍可见 |
| ≥840dp 纯阅读 | 可启用双页对开；允许切回单页 | 关闭或轻量菜单 |
| ≥840dp AI 协作 | 左侧单页正文，保留原文字符锚和 renderer 身份 | 右侧常驻 AI，目标 380–440dp，拖条调整约 36%–50% |

宽度按扣除系统 inset、Rail、折叠铰链后的实际空间计算。约束优先级：正文至少 400dp、AI 至少 360dp、铰链不盖正文；无法同时满足就回单页 Sheet，不硬塞两个不可读区域。400dp 为常见面板初值；380–440dp 和比例是可用空间内的目标，不能与最小正文宽冲突。

对开使用 R1 两页边界 `(pageIndex, pageIndex+1)`，尾页可空白，装订中缝静态细线，普通屏允许微阴影，E-INK 目标 0.5dp 灰线。用户翻一组两页仍按真实字符/CFI 保存，不将左/右页号当持久位置。AI 打开时双页转左单页，关闭后回原字符锚所在对开；折叠/旋转/调宽不能换书、丢选区/草稿/任务。

点 AI 来源：手机收起面板、正文定位并挂 QueryBack；宽屏面板保持，左侧跳转。见[阅读交互规范](inkflow-reader-interaction-spec.md)。

## 听书视图

全屏大封面、书名/章节、时间轴与章节时长抽屉；提供 15 秒前后跳、播放/暂停、定时关闭、音色、语速以及“仅应用当前书”。`原文` 返回正文句级高亮，读播位置不同出现“当前阅读与播放位置不一致 · 听当前”；播放位置和阅读位置分别保存，未经动作不相互覆盖。

正文点击当前朗读句暂停/续播的目标不能吞掉手柄或链接。无系统 TTS 引擎、网络失败和音频焦点丢失有可恢复状态；真实 TTS 未验收时不能用播放器界面存在代替通过。

## 数据、语言与验证

首页布局/皮肤等新增偏好进入 `native/settings.json` v5 扩展；复用现有 v22，读取 v1–v4 用明确默认值补新字段。壁纸/字体以已有资源路径与备份文件策略保存，失效资源可回退。设备显示策略、密钥、临时查看全部授权继续设备本地；不可把当次授权打包。v5 allowlist 与恢复校验已有扩展代码，仍须核验字段覆盖及 v1–v4 兼容，不能只凭版本号判定通过。Skill 定义可备份同步，本机默认/单书绑定继续设备本地，不进入备份或同步。

四语覆盖所有新 Tab、风格、错误、授权、语义标签和媒体通知；跟随系统/手动选择保持现有行为。界面语言不改用户书名/笔记/生成内容/翻译目标或音色。新增尺寸比较至少手机短屏、常规手机、≥840dp 和铰链约束；E-INK 用静态同语义流程。

放行要同时证明四首页全量、三 Tab 返回和深链、四语长文/大字号、双层皮肤隔离、无阅读现场重建、v5 恢复兼容及每阶段稳定性回归。当前三 Tab/四首页已有实现；[ReaderPageSpread.kt](../../android/app/src/main/kotlin/com/aceinandroid/inkflow/ui/reader/ReaderPageSpread.kt)、原生双页绘制、[ReadingWorkspaceHost.kt](../../android/app/src/main/kotlin/com/aceinandroid/inkflow/ui/ai/ReadingWorkspaceHost.kt) 调宽，以及 [NarrationPlayerScreen.kt](../../android/app/src/main/kotlin/com/aceinandroid/inkflow/NarrationPlayerScreen.kt) 已新增代码。双页/AI 联动、显示策略与真实听读属于部分实现待新验收；不能沿用旧基线的固定 400dp 描述，也不能由此宣告完整录屏体验通过。
